# RHEL 9 Linux Administration Lab

A hands-on Linux administration learning project covering system administration, troubleshooting, security, storage, networking, and Bash scripting using AWS EC2.

This repository documents my practical learning journey through individual Linux administration labs. Each lab focuses on understanding commands, performing configurations, troubleshooting issues, and verifying results.

## Lab Environment

- Operating System: Red Hat Enterprise Linux 9 (where verified)
- Cloud Platform: AWS EC2
- Access: SSH
- Shell: Bash

## Bash Scripting — Lab 15

Five foundational lessons covering:

- Bash fundamentals
- Conditions and decision making
- Loops
- Functions and script arguments
- Linux Server Health Check

The final exercise combines Bash functions and Linux utilities to check disk usage, memory, system information, and SSH service status.
